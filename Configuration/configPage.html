Noteboard

The noteboard appears on the web client's home page. Users write notes and report media issues; issue reports are visible to administrators, who can resolve them.

Injects the noteboard into the web client (no disk changes needed; works in Docker). Takes effect on the next page load.
Off (default): users only see their own notes; admins always see everything. On: the board works like a shared bulletin board. Takes effect immediately.
Oldest notes are discarded beyond this limit.
